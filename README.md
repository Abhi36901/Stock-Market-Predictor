A machine-learning-powered web application that predicts stock prices using historical market data, technical indicators, and financial news sentiment analysis.

📌 Overview

Stock Market Predictor combines quantitative market data with qualitative information from financial news to estimate the next stock price and its expected direction.

The application provides a simple web interface where users can enter a stock ticker and receive a prediction.

✨ Features

Search for stocks by ticker symbol

Fetch historical market data using yfinance

Calculate technical features from historical prices

Predict the next stock price using a machine-learning model

Predict whether the stock is expected to move up or down

Analyze financial news sentiment

Display results through a web-based interface

Deployed as a live web application using Vercel

🧠 Machine Learning

The prediction pipeline uses historical stock-market information and engineered features such as:

Close Price — historical closing price

Return — daily percentage return

MA10 — 10-day moving average

MA50 — 50-day moving average

Volume — trading volume

Volatility — recent variability in returns

Momentum — recent price-trend indicator

Financial Sentiment — sentiment extracted from financial news

The system produces two main outputs:

Predicted Price — estimated future closing price

Predicted Direction — whether the predicted price is higher or lower than the current price

📊 Model Evaluation

The model was evaluated using time-based cross-validation to avoid randomly mixing future observations into the training data.

Metrics

MAE (Mean Absolute Error): average absolute difference between predicted and actual prices.

RMSE (Root Mean Squared Error): measures prediction error while penalizing larger errors more strongly.

Direction Accuracy: percentage of cases where the model correctly predicts whether the stock moves up or down.

Stock prices are inherently difficult to predict. These results are experimental and should not be interpreted as financial advice.

⚙️ Run Locally

1. Clone the repository

git clone https://github.com/Abhi36901/Stock-Market-Predictor.git
cd Stock-Market-Predictor

2. Create a virtual environment

Windows:

python -m venv venv

Activate it:

venv\Scripts\activate

3. Install dependencies

pip install -r requirements.txt

4. Run the Flask application

python app.py

Then open the local address shown in the terminal, typically:

http://127.0.0.1:5000
