# Stock Market Predictor

A machine-learning-powered web application that combines historical stock market data, technical indicators, and financial news sentiment analysis to predict stock prices and estimate market direction.

[**Live Demo**](https://stock-market-predictor-two.vercel.app/) 
## Overview

The Stock Market Predictor explores how quantitative market data and qualitative financial news can be combined to generate stock price predictions.

Users can enter a stock ticker symbol and receive an estimated future closing price alongside a predicted market direction. The application retrieves historical market data, engineers relevant features, analyzes financial news sentiment, and uses machine learning models to generate predictions.

The project was developed to explore the practical application of machine learning, financial data analysis, and natural language processing in a web-based application.

## Features

- **Stock Search:** Enter a stock ticker symbol to analyze a selected stock.
- **Historical Market Data:** Retrieve historical stock prices and trading volumes using `yfinance`.
- **Technical Feature Engineering:** Calculate moving averages, returns, volatility, and momentum indicators.
- **Machine Learning Predictions:** Estimate future closing prices using regression-based models.
- **Market Direction Prediction:** Classify the expected movement as upward or downward.
- **Financial Sentiment Analysis:** Extract sentiment from financial news to incorporate qualitative market information.
- **Web Interface:** Display predictions and analysis through a Flask-powered application.
- **Live Deployment:** Access the application through its Vercel deployment.

## How It Works

The application follows a pipeline that combines historical price analysis with financial news sentiment.

1. **Stock Selection:** The user enters a ticker symbol through the web interface.
2. **Data Retrieval:** Historical market data is fetched using `yfinance`.
3. **Feature Engineering:** The application calculates indicators such as moving averages, daily returns, volatility, and momentum.
4. **Sentiment Analysis:** Available financial news is processed to estimate market sentiment.
5. **Model Prediction:** The machine learning pipeline uses the engineered features to estimate the next closing price and expected direction.
6. **Results Display:** The predicted price and directional estimate are presented through the web interface.

## Machine Learning and Feature Engineering

The prediction pipeline combines historical market information with engineered numerical features and financial news sentiment.

| Feature             | Description                                           |
| ------------------- | ----------------------------------------------------- |
| Close Price         | Historical closing price of the stock                 |
| Return              | Daily percentage change in price                      |
| MA10                | 10-day moving average                                 |
| MA50                | 50-day moving average                                 |
| Volume              | Number of shares traded                               |
| Volatility          | Measure of recent variability in returns              |
| Momentum            | Indicator representing recent price movement          |
| Financial Sentiment | Sentiment score derived from available financial news |

### Prediction Outputs

**Predicted Price:** An estimated future closing price generated by the regression model.

**Predicted Direction:** An estimate of whether the stock price will move upward or downward relative to the reference price.

The application explores the combination of quantitative indicators and qualitative sentiment rather than relying on historical closing prices alone.

## Model Evaluation

The model was evaluated using time-based cross-validation to better reflect the chronological nature of financial data and reduce the risk of training on future observations when evaluating past predictions.

The current reported evaluation results are:

| Metric             | Result |
| ------------------ | -----: |
| Price MAE          |   2.60 |
| Price RMSE         |   3.57 |
| Direction Accuracy |  53.6% |

### Understanding the Metrics

- **Mean Absolute Error (MAE):** Measures the average absolute difference between predicted and actual stock prices.
- **Root Mean Squared Error (RMSE):** Measures prediction error while penalizing larger errors more heavily.
- **Direction Accuracy:** Measures the percentage of evaluated cases in which the predicted market direction matched the actual direction.

The reported direction accuracy of 53.6% indicates modest directional predictive performance. Results may vary by stock, evaluation period, market conditions, and model configuration. Price error metrics are expressed in the same currency units as the evaluated stock prices.

These results are experimental and do not establish that the model will outperform a market benchmark or generate profitable trading signals.

## Getting Started

### Prerequisites

- Python 3.x
- Git
- A modern web browser
- Internet access for retrieving market data and available financial news

### 1. Clone the Repository

```bash
git clone https://github.com/Abhi36901/Stock-Market-Predictor.git
cd Stock-Market-Predictor
```

### 2. Create a Virtual Environment

On Windows:

```bash
python -m venv venv
```

Activate the environment:

```bash
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```
